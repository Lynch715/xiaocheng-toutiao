# 小城头条

[手机和电脑均可在线游玩](https://lynch715.github.io/xiaocheng-toutiao/)

《小城头条》是一款以 2000 年代初为背景的地方报社经营游戏。选定报名、城市和创刊年份后，每周排头版、定印量，再看周六的发行回单。签发的报纸收入合订本，可下载 PNG。临渡和当地采访为虚构，游戏稿库含有历史事件改编稿。

进度保存在当前浏览器中。手机端可在屏幕底部切换工作区，在采编台直接查看头版和跳到印刷安排。

## 本地运行

在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

运行 `node pack.mjs` 可生成内嵌图片的独立试玩文件 `试玩版/小城头条.html`。
